## 로그인 모달 정확한 문구

- ko: 로그인하기 / 취소. 설명: 로그인하면 장소와 코스를 저장하고 좋아요, 후기 작성 등의 기능을 이용할 수 있어요.
- en: Log in / Cancel. 설명: Log in to save places and courses, like courses, and write reviews.
- ja: ログイン / キャンセル. 설명: ログインすると、スポットやコースの保存、いいね、口コミ投稿などを利用できます。
- 제목 및 전체 ko/en/ja 문구는 `resource-catalog.md`의 common_login_required_title 등 키를 따른다.

## 검증과 미검증

- 완료: test, detekt, :app:assembleDebug, :app:lintDebug, :app:compileDebugKotlin (401 tasks BUILD SUCCESSFUL). ktlint 포맷, 문자열/포맷 인자/255지역 리소스 검사 2개, Fastfile Ruby 구문 검사 통과.
- 비로그인 실제 에뮬레이터: 추천 저장→모달→취소→목록 유지, 재선택→로그인 화면 이동 확인. 로그인 후 동작 자동 재실행 없음은 SessionUiStateTest로 확인.
- 영어 새 홈/게스트 AI/지역 인사는 실제 화면 캡처. AI 인사 캡처는 debug 예시 응답이며 실서버 대화 전체 성공 증거가 아님.
- 사용자에게 번역 확인 완료를 전달받아 추가 수동 번역 검증/촬영은 중단. 최종 AI 일본어/결과 상태, 로그인 모달 영어·일본어, 모든 저장·후기·신고 진입별 스크린샷은 미촬영. 이전 지역/장소/마이/언어 화면 이미지는 해당 작업 당시 빌드이며 최종 통합 빌드 전수 캡처가 아님.
- 실기기·모든 계정/데이터·MT 품질 전수 검증은 하지 않음. 서버 AI 세션 전체 E2E 미검증. iOS 구현은 이 PR에 포함되지 않음.
