지도·표·도서 카드는 같은 선택 상태를 사용한다. 시·도 전체는 2자리 코드, 시·군·구는 5자리 코드이며 섬별 새 코드를 만들지 않는다. `시·도를 누르면 지도가 확대돼요` 문구 및 지도 위 이름은 제거했다. 표는 3열, 행 최소 48dp, 최대 168dp(3.5행) 높이이며 다음 행을 반쯤 보여 주어 나머지 항목을 스크롤할 수 있음을 알린다. 도서 상자는 지도 좌상단(서쪽)·우상단(동쪽) 빈 공간에 배치하며 하단 출처 문구는 제거했다. 선택 요약은 알약 없이 한 줄이다. 지도 경계는 선택 여부와 관계없이 초록색을 유지하고, 선택 영역과 도서는 연한 초록색으로 채운다.

## 실행한 검증

- `:app:compileDebugKotlin`, `test`: 성공.
- `:app:assembleDebug`, `:app:lintDebug`: 최종 UI 기준 성공.
- `:main:presentation:detekt`, `:main:data:detekt`, `:main:domain:detekt`, `:main:entity:detekt`: 성공.
- 변경 Kotlin 파일 ktlint와 `git diff --check`: 성공.
- 독립 테스트: RegionMapViewModelTest 11개, RegionMapGeometryTest 6개, AreaMapDataTest 4개, LegalAreaCodeMapperTest 5개, InterestRegionRequestTest 4개 = 30개 성공. 경계 누락, 홀 방향, 전체에서 일부 제외·재포함, 법정동 배열 요청, 저장 실패 보호를 검사한다.
- 독립 아키텍처·좌표 변환 검토: DTO/VO 경계·MVI 유지 확인. 발견한 홀 방향과 확대 후 이동 범위 문제는 수정 후 재검증했다.
- 실제 에뮬레이터: 전국→시·도 확대, 도서 카드 선택, 표 선택·체크·자동 스크롤, 하위→전체 선택 시 1개 유지, 조회 실패 UI 확인. 가입/프로필 저장 요청은 제출하지 않았다.

서버 버전 제한을 피하기 위한 로컬 실행에만 `-PappVersionCode=2100000000`을 사용했다. 저장소 기본 versionCode나 출시 설정은 변경하지 않았다. 병렬 Gradle 실행 중 발생한 중간 lint 출력 파일 경합은 실행이 끝난 후 순차 재실행하여 최종 lint 성공을 확인했다.

## 남은 범위

BackEnd는 사용자 요청에 따라 수정하지 않았다. 시·도 prefix를 직접 보내는 방식을 폐기하고, 다운로드 법정동 자료의 활성 읍·면·동 5,067개 중 선택 범위의 10자리 코드 배열을 보낸다. 코드 집합은 기존 서버 seed와 일치하며 인천 전체 156개, 옹진군 제외 149개를 검증했다. 실제 운영 DB·저장 성공은 미검증이며 실패 시 선택을 유지한다.

화면·캐시는 시·도/시·군·구 선택을 유지한다. 전체에서 하위 지역을 누르면 해당 지역만 제외하며, 모든 하위 지역을 다시 포함하면 전체 한 항목으로 합친다. 인천 전체→옹진군 제외→재포함 시 전체 1개 복원을 실제 에뮬레이터에서 확인했다.

프로필 정상 편집 캡처는 기존 관심사 조회 실패로 미촬영이다. 프로세스 종료 후 미저장 선택 복원은 기존 인메모리 가입 홀더 범위에서 지원하지 않는다. 핀치 확대의 중심은 화면 중심이다.

[Courmy UI Flow](https://www.notion.so/3f6b448bdf9d81bea9f1f35597ec3d54)에 최신 전체·옹진군 제외 상태 2장과 법정동 배열 전송 명세를 추가했다. 기존 이미지 제자리 교체는 연결 도구가 no_match 오류를 반환하여 미완료이며, 기존 이미지·순서는 유지했다. 정상 편집 화면은 기존 이미지를 유지하고 미촬영 사유를 함께 기록했다.

## 색상 후속 검증

2026-11-02: 지도 경계를 초록색으로 고정하고 선택 영역을 연하게 변경했다. 색상 변경 APK assembleDebug·presentation detekt가 완료되어 설치 및 전체/옹진군 제외 상태를 캡처했다. 첫 lint는 course:presentation 분석기 내부 오류로 실패했고, 순차 재시도는 별도 지도 검색 변경의 MapPlaceSearchRepositoryImpl·PlaceSearchDataSource 컴파일 오류로 중단됐다. 따라서 색상 후속 수정의 최종 lint는 미완료다. 기존 30개 테스트 성공은 색상 수정 전 선택·전송 로직 검증 결과다.
