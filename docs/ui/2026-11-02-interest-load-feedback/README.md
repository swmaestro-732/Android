- 프로필 조회는 유지한다. 지역 지도 자산을 먼저 표시하고, 테마 카드는 원래 색상으로 유지한다.

- 안내 바는 그림자 없이 중립 배경·얇은 테두리·작은 글씨를 사용한다. 새로고침 터치 영역은 최소 48dp를 유지한다.
- 첫 조회 실패 시 선택·저장은 비활성화하고, 같은 위치의 작은 안내와 새로고침으로 복구할 수 있다. 지역 지도 탐색은 가능하다.
- 저장 실패 보호·최소 지역 1개/테마 3개 조건은 유지한다.
