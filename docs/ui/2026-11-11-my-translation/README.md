# 마이 코스 제목 온디바이스 번역 (2026-11-11)

ProfileCourseCard의 DsText에 누락된 autoTranslate=true를 추가했다. 마이 코스·계획과 다른 사용자 프로필의 공통 카드 제목에 적용된다. 서버 원문은 변경하지 않는다.

검증: assembleDebug, lintDebug, 변경 파일 ktlint 통과. 영어 설정의 마이 코스 목록에서 한국어 제목이 영어로 바뀐 UI hierarchy를 확인했다. 계획은 현재 0개라 실데이터 검증하지 못했다. 일본어와 다른 사용자 프로필은 이번 수정 후 수동 확인하지 않았다.

스크린샷: 공유 에뮬레이터가 촬영 도중 다른 화면으로 이동해 수정 후 마이 화면 이미지는 확보하지 못했다. Notion 기존 이미지는 유지한다. 번역 모델의 부자연스러운 표현이나 일부 원문 잔존은 이 연결 수정과 별개다.
