# 지역별 코스 선택기 · 2026-11-11

- 가로 목록을 기본 접힘 선택기로 변경했다. 펼치면 여러 줄 칩을 최대 280dp 안에서 세로로 스크롤한다. 선택하면 자동으로 접히며 현재 선택명이 남고 피드 상단으로 이동한다.
- 전체 지역은 시·도 코드, 개별은 기존 SIGUNGU 코드로 요청한다. 일반 테마 화면의 가로 칩은 유지한다.
- 번들 지도 255개 지역 코드에 ko/en/ja 리소스를 연결했다. 미등록 코드는 원문을 유지한다.
- 로딩·오류/재시도·세부 지역 없음 상태, 펼침/선택 접근성 상태, 공통 DsChip 크기 기준을 사용한다. 공통 DsChip의 텍스트를 가로·세로 중앙 정렬해 사용자 지적을 반영했다.

## 범위와 제한

명칭은 앱용 로마자/가타카나 표기이며 모든 공식 외국어 명칭을 전수 검증한 것은 아니다. 대표 참고: [종로구 영문](https://www.jongno.go.kr/englishMain.do), [인천 영문 구군](https://www.incheon.go.kr/en/EN010103), [인천 일본어 구군](https://www.incheon.go.kr/jp/JP010103), [성동구 일본어](https://sd.go.kr/jpn/contents.do?key=4582). 일본어는 가타카나+市/区/郡으로 통일했다.

지역 선택 후 다른 지역 제목의 코스가 여전히 표시된다. 요청 코드와 UI 선택은 유지했으나 서버의 실제 지역 필터 반영 및 코스 지역 메타데이터 정확성은 미검증이다. 한국어/일본어·오류/재시도·큰 글꼴 전 상태는 수동 캡처하지 않았다.


## 칩 크기 통일 후속 수정

사용자 요청으로 지역 선택 칩 두 곳의 별도 최소 높이 48dp를 제거했다. 다른 화면과 동일하게 textRegularXS, 좌우 15dp·상하 8dp 여백으로 크기를 계산한다. 중앙 정렬은 유지하며, 펼침/접힘 헤더의 최소 높이 48dp는 칩과 별개로 유지한다.
