# 장소 상세 운영 시간 번역 (2026-11-11)

운영 시간만 원문+번역 병기에서 선택 언어 한 줄로 변경. 한국어는 원문 유지. 선두 요일 토큰과 휴무·정기휴무·매일·연중무휴는 언어 리소스 사용. 기타 자유 안내 문구는 기존 온디바이스 번역 사용, 대기/실패 시 원문 fallback. 시간 숫자는 유지한다. 오늘 강조와 접힘/펼침 동작 유지.

검증: assembleDebug/lintDebug/변경 파일 ktlint 통과, 문자열 리소스 검사 2개 통과. 에뮬레이터 최신 APK에서 카멜커피의 영어 접힘(Wed 10:00 - 18:00)과 펼침(Mon–Sun) 확인. 일본어 및 휴무 데이터 수동 검증 미실시.
