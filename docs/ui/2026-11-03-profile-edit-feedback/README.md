# 프로필 편집 조회 안내 (FS-26)

2026-11-03 · 최신 debug APK · Pixel 9 실제 화면.

관심 테마/지역 편집과 같은 오류 보호 방향을 프로필 편집 화면에도 적용한다.

- 전체 오류 화면·상단 `다시 시도` 버튼을 없애고, 저장 버튼 위에 작은 안내 바(`InterestLoadFeedback`)를 둔다.
- 입력칸·아바타·관심사 영역은 그대로 유지한다. 조회 실패에도 화면을 통째로 가리지 않는다.
- 조회 실패: `잠시 후 다시 시도해 주세요.` + `새로고침`(contentAccent). 그림자 없이 중립 배경·얇은 테두리·작은 글씨.
- 최초 조회 전(`profile == null`)에는 저장 버튼이 비활성이라 알 수 없는 값을 빈 값으로 덮어쓰지 않는다.
- 이미 프로필을 받은 뒤의 복귀 새로고침은 기존 입력값을 유지하므로 로딩 바를 띄우지 않는다.

## 실제 캡처

- [정상 조회](normal.png): 로그인된 세션에서 값이 채워진 정상 상태. 상단 오류 텍스트 없이 하단 바 영역도 비어 있다.
- [조회 실패](error.png): 네트워크 차단(비행기 모드)으로 최초 조회가 실패한 상태. 폼은 유지되고 하단에 안내 바·새로고침, 저장 버튼 비활성.

실제 에뮬레이터의 프로필 조회 실패 상태를 직접 촬영했다. 예시 데이터로 성공 응답을 대체하지 않았으며 저장 요청은 제출하지 않았다. 로딩 바는 순간 상태라 별도 캡처하지 않았다(조건 동일: `isLoading && profile == null`).

## 검증

`:main:presentation:compileDebugKotlin`, `:main:presentation:detekt`, 변경 파일 ktlint(1.8.0) 통과, pre-commit 통과. UI 전용 변경이며 상태·API 계약·서버 요청은 바뀌지 않았다.
