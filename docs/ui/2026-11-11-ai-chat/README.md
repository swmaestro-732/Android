최신 검증 빌드는 2000000023 / 1.3.999다. 홈은 최신 23 빌드로 재촬영했으며 지역은 해당 UI가 확정된 당시 빌드의 원본이다. 최종 PR 준비 시 추가 촬영을 시도했으나 에뮬레이터가 다른 화면/상태로 전환되어 최신 빌드 전체 캡처 완료로 주장하지 않는다.

로그인 게이트·테마·장소·장소 후보·오류·빈 결과 화면의 최종 빌드 캡처는 미완료다. 실제 서버 대화 전체 왕복과 운영 장소 검색·Redis·버전 정책은 미검증이다. ViewModel fake repository 테스트는 상태 전이·중복 요청 방지·세션 초기화·오류 후 입력 복구 등을 검증하며 운영 성공을 보장하지 않는다.

## 최종 결과 카드

- 64dp 썸네일, 상단 패딩 10dp, 텍스트와 상단 정렬.
- 카드 최대 폭 272dp, 패딩 10dp, 요소 간격 10dp, 카드 간격 8dp, 라운드 16dp.
- 테마 1줄, 제목 최대 2줄 + Ellipsis. 최소 내용은 썸네일 높이에 맞추며 고정 전체 높이 없음.
- 저장/좋아요와 오른쪽 chevron 없음. 카드 전체 탭은 코스 상세로 이동.

## API 및 위치 제한

- 첫 화면은 앱에서 그리며 첫 답변 전 API 호출 없음. 앱 지역 칩은 모두 TEXT. 내 근처 고정 칩 없음.
- 마지막 위치(lastLocation)와 현재점/약 1.5km 북동남서 샘플 주소로 구·군 우선, 없으면 시, 중복 없이 최대 3곳. 정확한 인접 지역/거리순 목록은 아님. 위치 신선도 검증/새 GPS 측정 없음.
- 위치/주소가 없으면 직접 입력. 동일 구 이름의 시도 구분, 텍스트 100자 제한의 프런트 검증, 4400/4401 서버 코드 세분 처리는 후속 확인 필요.
- 실제 서버 주소 변경은 ignored local.properties의 로컬 설정으로만 했으며 PR에 secret/설정 파일을 포함하지 않는다. 높은 테스트 버전 역시 Gradle 실행 인자만 사용했으며 저장소 기본 버전을 변경하지 않는다.

## RESULT 입력 영역 숨김

RESULT에서는 메시지 입력창과 전송 버튼을 렌더하지 않는다. 하단 시스템 영역 여백은 유지하고 서버 quickReplies로 재추천/처음부터를 제공한다. 재추천 전송 중에도 RESULT면 숨김 유지. 처음부터로 REGION 복귀 시 입력 영역을 다시 표시한다. PLACE_CONFIRM 등 다른 단계는 기존 input.enabled 제어를 따른다.

후속 변경 검증: assembleDebug, lintDebug, main:presentation:testDebugUnitTest 통과. 실제 에뮬레이터 debug 결과의 EditText·보내기 노드 부재와 RESTART 후 두 노드 복원을 확인했다. 전체 518개 테스트는 이전 PR 검증 기록이며 이번 후속 작업은 해당 모듈 151개를 재실행했다.

## 홈 배너 최종 스타일

테두리를 제거하고 뒤쪽 그림자를 16dp, ink spot 20% / ambient 8%로 적용했다. 파스텔 배경·22dp 라운드·문구·CTA는 유지한다. 미사용 cardBorder 색상도 제거했다. 2000000022 / 1.3.999 APK·Lint 통과, 실제 홈 캡처로 테두리 제거 확인.

## 응답 전환 및 홈 CTA 최종

성공 응답은 최소 900ms 동안 답변을 준비하고 있어요 + 점 3개를 표시한 뒤 적용한다. 서버 요청과 최소 시간은 동시에 진행하여 느린 응답에 추가 지연은 없으며 오류는 즉시 안내한다. 초기화 시 대기 중 응답을 취소한다.

홈 CTA의 흰 알약과 원형 화살표를 제거했다. 우측 textStrongS/contentAccent 텍스트와 20dp 대각선 화살표(기존 위 화살표를 45도 회전), 간격 8dp·상단 패딩 4dp. 카드 전체 클릭 유지.

후속 검증: 모듈 155개 테스트·APK·Lint·포맷 통과. 빠른 응답 899/900ms 경계·느린 응답 추가 지연 없음·오류 즉시 안내·대기 중 초기화 회귀 테스트 포함.
