# 프로필 관심사 서버 조회 보완

상태: 구현·자동 검증 완료, 정상 로그인 화면 최종 캡처 미확정 (2026-11-02).

## API 흐름

- 가입: `POST /api/v1/auth/signup`의 `areaCodes`에 활성 10자리 법정동코드 배열을 넣는다.
- 관심 지역 수정: `PATCH /api/v1/users`, body는 `areaCodes` 배열이며 다른 편집 필드는 변경하지 않는다. 시·도/시·군·구 prefix는 요청 직전 법정 읍·면·동으로 펼친다. 인천 전체 156개, 옹진군 제외 149개다.
- 테마 수정: 같은 PATCH의 `likeThemes`에 `ACTIVITY`, `CULTURE`, `DATE` 같은 대문자 코스 태그 enum을 보낸다.
- 관심사 조회: 기존 서버 `GET /api/v1/users`의 `data.likeThemes`, `data.areas[{code,name}]`를 읽는다. 기기 캐시가 응답을 덮어쓰지 않는다. 코스·카운트는 기존 `GET /service/v1/mypage`를 유지한다.
- 서버 법정동 목록이 상위 범위의 모든 동을 포함할 때만 시·도/시·군·구 선택으로 묶는다. 일부 동만 포함하면 원래 동 선택을 보존하며, 빈 배열은 빈 선택이다.
- BackEnd 코드는 수정하지 않았다. 이 작업에서 실제 저장 요청은 제출하지 않았다.

## 오류 보호

조회 실패는 빈 선택 성공으로 처리하지 않고 재시도를 제공한다. 프로필 원본이 없으면 저장을 막는다. 테마 저장 중 중복 제출·선택 변경을 막고, 실패하면 선택을 유지하며 성공한 경우에만 화면을 닫는다. 기존 테마 최소 3개 조건은 유지한다.

## 검증

- 전체 `test`, `:app:assembleDebug`, `:app:lintDebug`, `:main:presentation:detekt`, `:main:data:detekt` 통과.
- 서버 관심사 매핑·캐시보다 우선·빈 배열·실패/필드 누락, 법정동 복원·제외 보존, 테마 조회/저장 실패·중복 방지 회귀 테스트 통과.
- 실행 로그에서 `GET /api/v1/users`의 200 응답과 관심 테마·지역 필드를 확인했다. 인증 헤더·토큰은 문서에 기록하지 않는다.
- 로그인된 에뮬레이터가 다른 화면 작업에도 사용되어 정상 화면 최종 캡처는 확정하지 못했다. 별도 검증 기기는 로그인 조건으로 조회 실패 상태를 실제 확인했다. 테스트 데이터를 실제 사용자 응답처럼 캡처하지 않았다.
- 최신 debug APK의 `profile-load-error.png`는 프로필 조회 재시도·저장 비활성, `theme-load-error.png`는 테마 조회 재시도·칩/저장 비활성 상태다. 로컬 확인용 versionCode만 높였으며 출시 설정은 변경하지 않았다.
- Courmy UI Flow의 기존 정상 편집 이미지는 유지하고 미갱신 사유와 실제 오류 상태 캡처를 추가한다.
